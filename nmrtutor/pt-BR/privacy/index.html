Política de privacidade do Laboratório RMN FID

Data de vigência: 2026-08-22

O Laboratório RMN FID funciona sem conta ou serviço on-line operado pelo desenvolvedor. O app não coleta dados nem rastreia você.

A política de privacidade em inglês é a versão oficial. Esta tradução é fornecida para conveniência.

Coleta de dados e rastreamento

O app não contém publicidade, análise, rastreamento, contas de usuário ou serviço de rede operado pelo desenvolvedor. Ele não envia ao desenvolvedor dados de uso nem dados científicos importados.

Arquivos importados e trabalho salvo

Os conjuntos de dados de RMN são abertos e processados no seu dispositivo. Arquivos e espaços de trabalho permanecem em locais controlados por você e só saem do app quando você os exporta, copia ou compartilha explicitamente.

Áudio dos gráficos

O áudio é gerado a partir dos dados dos gráficos para reprodução ou exportação. O app não usa o microfone para gravar áudio.

Correspondência de suporte

Ao enviar um e-mail ao suporte, você escolhe as informações fornecidas. Elas são usadas apenas para responder e gerenciar a solicitação e mantidas somente pelo tempo razoavelmente necessário. Não envie dados científicos confidenciais ou identificáveis, exceto quando isso for necessário e apropriado.

Este site

Este site estático não adiciona análise, publicidade, formulários de contato ou cookies de rastreamento. O GitHub hospeda o site e pode processar informações técnicas comuns das solicitações conforme sua própria declaração de privacidade.

Alterações e contato

Esta política será atualizada se as práticas de dados do app mudarem. Perguntas ou solicitações podem ser enviadas para utchemnmr@gmail.com.
